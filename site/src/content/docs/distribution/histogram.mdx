A histogram shows the shape of one number across many observations. OpenChart bins the raw values, counts each bin and draws a bar per bin on a continuous x axis, so bar widths follow the value range instead of equal-width categories.

Use a [density curve](/docs/distribution/density/) when you want the shape without bin edges, or a [beeswarm](/docs/distribution/beeswarm/) when every observation should stay visible. If you already have one total per category, a [bar chart](/docs/comparison/bar/) is the right chart.

## A basic histogram

Set `mark` to `{ type: "histogram", binCount: 24 }`, which asks for up to 24 bins, and put the raw field on `x`. Each row of the data is one observation, and the y axis defaults to the count per bin. `binCount` defaults to 20.

## Fewer bins

`binCount` sets the most bins you want. OpenChart rounds the bin width to a round step (1, 2 or 5 times a power of ten), so the count you get can differ. Wider bins give a smoother outline and lose detail. The data is the same as the first figure.

## Overlapping groups

Add a `color` channel and each group gets its own histogram. Without `stack`, the groups overlap at the same x and the fill drops to 55% opacity, so both shapes stay visible. Overlap suits comparing where two groups sit on the same scale.

<Demo id="distribution/histogram-overlap" />

## Groups as shares

`normalize: true` plots each group's share of its own total instead of a raw count, and formats the y axis as a percentage. Use it when the groups have different sizes, since raw counts would let the larger group dominate.

## Fields that matter

| Field | What it does |
| --- | --- |
| `mark.type` | `"histogram"` bins the `x` values and counts each bin. |
| `mark.binCount` | The bin count to aim for; the bin width is rounded to a round number. Defaults to 20. |
| `mark.normalize` | Plots each group's share of its own total. Formats the y axis as a percentage. |
| `mark.fillOpacity` | Overrides the 55% opacity used for overlapping groups. |
| `encoding.x` | The raw quantitative field to bin. Required. |
| `encoding.y` | Optional. Defaults to the count per bin. |
| `encoding.color` | Optional. One overlapping histogram per group. |
| `labels` | Has no effect on a histogram, and the compiler warns if you set it. |

A tick strip draws one short line per observation along a value axis, so the whole spread of a group reads at once: where values cluster, where they thin out and where the extremes sit. Stacking one strip per group lets you compare spreads directly.

Ticks overlap when the data is dense. Switch to a [beeswarm](/docs/distribution/beeswarm/) to dodge the points apart, or to a [histogram](/docs/distribution/histogram/) when counts matter more than individual values. To compare one summary number per group, use a [bar chart](/docs/comparison/bar/).

## A basic tick strip

Set `mark` to `"tick"`, put the value on `x` and the group on `y`. Each row of the data becomes one tick. The tick mark needs a `y` channel; the spec fails validation without one.

<Demo id="distribution/tick-basic" />

## Colored strips

A `color` channel on the same field as `y` gives each strip its own color. The strips are already labeled on the axis, so `legend: { show: false }` drops the legend.

<Demo id="distribution/tick-groups" />

## A reference line

A `refline` annotation draws a threshold in data units across every strip, so you can read how many ticks fall on each side. Here the line marks four hours.

## Fields that matter

| Field | What it does |
| --- | --- |
| `mark` | `"tick"` draws one short line per row. |
| `encoding.x` | The quantitative value each tick is placed at. |
| `encoding.y` | A nominal field that names each strip. Required for the tick mark. |
| `encoding.color` | Optional. Colors each strip by group. |
| `legend.show` | Set to false to hide a legend the axis labels already replace. |
| `annotations` | A `refline` with `x` draws a reference value across the strips. |

A sparkline is a trend with everything else removed: no title, axes, legend or source line. It sits next to a number you render yourself, such as a KPI card or a table cell, and answers whether the number is going up or down.

Use a full [line chart](/docs/change-over-time/line/) when the reader needs to read values or dates off the axes. A sparkline shows no axes, so pair it with the figures it summarizes. For sparkline cells inside tables, see [data table](/docs/tables/data-table/).

## A line sparkline

Set `display: "sparkline"` on a line or area spec. The engine strips chrome, axes, legend and watermark, so the chart fills whatever box you give it. The docs recommend a fixed height of 36 to 56 pixels. Without `stroke`, the line is colored by its trend: the theme's positive color when it rises, negative when it falls. The first demo sets `stroke` to use an accent color instead.

## An area sparkline

Swap the mark to `"area"` for a filled version. The channels are the same: a position field on `x` and the value on `y`. With no `stroke`, the trend color drives both the line and the fill.

## The last-point dot

A sparkline marks its last point by default. `point: "first"` moves the dot and `point: false` removes it, as here.

## A taller box

A sparkline has no size of its own. It fills the box it is mounted in, so a taller box gives the same series more vertical room. Pick the height from the layout the sparkline sits in.

## Fields that matter

| Field | What it does |
| --- | --- |
| `display` | `"sparkline"` strips chrome, axes, legend and watermark. The default is `"full"`. |
| `mark` | `"line"` or `"area"`. An object sets `stroke` and `point`. |
| `mark.point` | The last point is marked by default. `"first"` moves the dot to the first point and `false` removes it. |
| `encoding.x` | The position of each reading. An ordinal field is enough when you only need the order. |
| `encoding.y` | The value that sets the height of the line. |

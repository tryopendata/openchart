A calendar heatmap draws one cell per day, with weeks as columns and weekdays as rows, and colors each cell by that day's value. It suits daily data where seasonality, streaks and weekday patterns matter more than exact values.

Use a [line chart](/docs/change-over-time/line/) when the reader needs to read values off an axis or compare a few series, and a [heatmap](/docs/correlation/heatmap/) when the two axes are categories rather than dates. A calendar has no axes at all, so the color legend is the only way to read a number.

## A basic calendar

`x` is the daily date with `type: "temporal"`, one row per day, and `color` is the quantitative value. There is no `y` channel, because the calendar computes its own weeks-by-weekdays layout. A diverging scheme such as `redBlue` suits values that run above and below a normal, and `reverse: true` makes warm days red. `format` sets how the legend prints values. Days with no data row render as empty cells, so the grid always shows the whole year, and these demos fill a few weeks of it.

## Sunday weeks and rounder cells

Two mark options change the grid. `weekStart` sets which weekday sits in the top row, `"monday"` by default or `"sunday"`. `cellRadius` sets the corner radius of each day cell in pixels. This demo also swaps in a sequential scheme, `"blues"`, because the values here run from low to high rather than around a midpoint.

<Demo id="change-over-time/calendar-sequential" />

Data that spans several years splits into one band per year. The bands stack and share a single color scale and a single legend, so colors compare across years.
## Fields that matter

| Field | What it does |
| --- | --- |
| `mark` | `"calendar"`, or an object with `weekStart` and `cellRadius`. |
| `encoding.x` | The date of each day, `type: "temporal"`. |
| `encoding.color` | The quantitative value that colors each cell. It also drives the legend. |
| `encoding.color.scale.scheme` | A named color scheme, such as `"redBlue"` or `"blues"`. |
| `encoding.color.scale.reverse` | Flips the direction of the scheme. |
| `encoding.color.format` | A d3-format string for the legend values. |
| `mark.weekStart` | `"monday"` or `"sunday"`: the weekday in the top row. |
| `mark.cellRadius` | Corner radius of day cells, in pixels. |

A race plays the top entries in a ranking one period at a time. Use it when the order of events is the story, such as which economies passed Japan and when. Use a [bump chart](/docs/change-over-time/slope-bump/) to compare rank across several periods, or [small-multiples line charts](/docs/composition/facets/) to compare how values changed for each series. Readers can scrub a race, but they can't compare two moments that never share the screen.

## Bar race

Set `type: "race"` and `mark: "bar"`. Each row supplies one country's GDP for one year. The race ranks the countries each year and moves the bars between ranks as the values change. `encoding.value.format` uses `$.3~s` to show values such as `$4.03T`.

## Line race

Set `mark: "line"` to trace the ranked series up to the playhead. The x axis grows with the playhead by default. Use `mark: { type: "line", window: "all" }` to show the full time axis while the lines draw in.

<Demo id="change-over-time/race-line" />

## Table race

Set `mark: "table"` when readers need the rank and value in columns. The default columns include an inline bar and each entry’s share of the total. Below 520px of table space, the bar hides and the Change heading becomes an arrow to leave more room for names. Use `columns` to pick which columns to show.

<Demo id="change-over-time/race-table" />

## Loop the top five

`race.top: 5` limits the ranking to five slots. `race.loop: true` restarts the race after the final hold, which lasts 1,500 milliseconds by default.

<Demo id="change-over-time/race-loop" />

## Fixed scale

The default `race.rescale: "frame"` fits the bar scale to each frame. Set `"fixed"` to hold that scale across the whole run. Early bars can look short when the values grow substantially over time. Line races fit the y axis to the history through the playhead.

## Playback and controls

A race plays with the same clock, controls and keyboard as every other playback chart, so the [playback page](/docs/change-over-time/playback/) covers when it starts, the player, the keyboard and reduced motion. The timing fields (`duration`, `step`, `holdEnd`, `loop`, `autoplay`, `controls`, `gaps` and `period`) go in either the `race` block or a top-level `playback` block, with the same defaults. Setting one field in both blocks is an error.

## Runtime API

In vanilla JavaScript, `createRace(container, spec)` returns the player. Call `play()` or `pause()` to control it, and `seek(t)` to move to a zero-based period index. Fractional indices land between periods. `update({ ...spec, mark: "line" })` swaps the mark at the current playhead, as in the first example. `on("period", callback)` listens for period crossings and seeks and returns an unsubscribe function. Call `destroy()` when you remove the player.

Use `setTheme({ theme, darkMode })` to replace the mount-level theme and color scheme during playback. Omit `theme` to use the spec's theme, or `darkMode` to use light mode.

To render the final frame as a standalone SVG, use `renderRaceStaticSVG(spec, options)` from `@opendata-ai/openchart-vanilla/static`.

Install the optional `gifenc` package to export GIFs. `await player.export("gif")` returns a `Blob` of the full run for bar and line marks. To export a race shown as a table, switch it to bar or line first.

## Fields that matter

| Field | What it does |
| --- | --- |
| `type` | `"race"`. |
| `mark` | `"bar"`, `"line"` or `"table"`. Use an object for options such as a line's `window` or a table's `columns`. |
| `encoding.time` | The period field. Quantitative and temporal fields sort by value. Ordinal fields use the order in the data unless you set `sort`. |
| `encoding.key` | The field that identifies the same entry across periods. Supply one row per key and period. |
| `encoding.value` | The numeric field to rank and draw. Set `format` here for the value labels. |
| `race.top` | Number of ranked slots. Defaults to 10. |
| `race.swap` | Milliseconds a bar takes to move to its new rank. Defaults to 400. |
| `race.rescale` | For bars and inline table bars, `"frame"` fits each frame, `"fixed"` uses one scale, and `{ min }` sets a floor on the frame maximum. |
| `race.summary` | `"sum"` shows the total of the top entries. Defaults to `false`. |
| `playback` | Timing and controls, shared with other playback charts. See [Playback](/docs/change-over-time/playback/) for each field and its default. |

A bubble playback moves every bubble from one period to the next, so readers watch countries travel across a scatter over decades. Use it when the path is the story, such as China's life expectancy rising decades before its income did. To compare two moments side by side, use [small multiples](/docs/composition/facets/) instead, since a playback shows one period at a time.

## Add time and key to a bubble chart

A bubble playback is a [bubble chart](/docs/correlation/bubble/) with two more channels. `encoding.time` names the field whose values are the periods, and `encoding.key` names the field that identifies each bubble from one period to the next. Supply one row per key and period.

```json title="gapminder.json"
{
  "mark": "point",
  "data": [
    { "country": "China", "region": "Asia & Pacific", "year": 1960, "gdp": 90, "life": 33.4, "pop": 667.1 }
  ],
  "encoding": {
    "x": { "field": "gdp", "type": "quantitative", "scale": { "type": "log" } },
    "y": { "field": "life", "type": "quantitative" },
    "size": { "field": "pop", "type": "quantitative" },
    "color": { "field": "region", "type": "nominal" },
    "key": { "field": "country", "type": "nominal" },
    "time": { "field": "year", "type": "temporal" }
  },
  "playback": { "duration": 20000, "labels": ["China", "India", "United States"] }
}
```

Without `key` the spec fails validation, because nothing else ties China in 1960 to China in 1962. Two rows with the same country and year fail too, with a message asking you to aggregate them. Use `mark: "point"`. A `circle` mark is a dot plot with a category on y, so it rejects the quantitative life expectancy axis.

The `playback` block sets the timing and controls, and the [playback page](/docs/change-over-time/playback/) lists every option with its default.

## Axes that hold still

The axes, the size scale and the region colors are computed once over every period and stay fixed for the run, so a bubble moves only when its country's numbers change. The x axis here runs from $10 to $100,000 in every frame, enough for Myanmar's $12 in 1966 and the United States' $76,657 in 2022.

GDP per capita grows by orders of magnitude, so x uses `scale: { type: "log" }` and equal steps right mean equal multiples of income. Between two periods a bubble moves along a geometric path on a log axis, so its motion matches the axis. A log axis can't show zero or negative values, so playback treats them as missing and warns with the count.

A bubble chart without `time` draws a trend line by default. A time spec draws none, and an authored `trendline` is an error.

## Name a few countries

`playback.labels` lists keys whose name stays beside their bubble for the whole run. The labels are never hidden to avoid collisions, so they never flicker on and off between frames. Name the handful of countries the title is about rather than every one.

The large faint year behind the bubbles is the period label. It uses the time channel's format; set `playback.period.format` to change it, or `playback.period: false` to hide it.

## Trails

<Demo id="correlation/bubble-playback-trails" />

`playback.trails` draws each named key's path so far: a thin line in the bubble's color through every period it has reached, with a small dot at each one. China's trail climbs steeply until about 1980 and then runs right. `trails: true` draws one for every key, and above 30 keys the engine warns that the chart will be crowded.

## Countries that appear and disappear

A country without values for a period is absent from it. Russia enters in 1988 and Afghanistan in 2000, the first years the World Bank reports their GDP per capita. Each fades in over the second half of the interval before it appears, and a country that stops reporting fades out over the first half of the interval after its last value. A missing period between two reported ones is filled in by default; `playback.gaps` sets that.

## Hover and legend

Hovering a bubble shows the values from the nearest period, titled with that period, such as 1986, rather than numbers interpolated between two years. When the nearest period was filled in for a gap, the title says "estimated". Clicking a region in the legend hides its bubbles without rescaling the axes.

## Static output

`compileChart`, `renderStaticSVG` and a page without JavaScript draw the final period, with its year as the period label. To draw another period, pass `t` to `renderStaticSVG`:

```ts title="static.ts"
import { renderStaticSVG } from "@opendata-ai/openchart-vanilla/static";

const svg1990 = renderStaticSVG(spec, { width: 720, height: 500, t: 15 });
```

`t` counts periods from zero, and this data has one every other year, so `t: 15` is 1990. A fraction draws the frame between two periods.

## Fields that matter

| Field | What it does |
| --- | --- |
| `mark` | `"point"`. |
| `encoding.x`, `encoding.y` | The two quantitative fields. `scale: { type: "log" }` suits income. |
| `encoding.size` | A quantitative field mapped to bubble area. |
| `encoding.color` | A category field. Every category keeps its color for the whole run. |
| `encoding.key` | Required. The field that identifies each bubble across periods. |
| `encoding.time` | The period field: `temporal`, `ordinal` or `quantitative`. |
| `playback.labels` | Keys whose name stays beside their bubble. |
| `playback.trails` | `true` or a list of keys whose path to draw. |
| `playback.period` | The large period label's `format` and `position`, or `false`. |

A sankey diagram shows how a quantity moves between stages: energy from its sources to the sectors that use it, money from revenue streams to departments, visitors from a landing page to a paid plan. Each ribbon's width is in proportion to the amount it carries, so the reader sees where most of the flow goes and where it leaks away.

Use a [stacked bar](/docs/comparison/grouped-stacked/) instead when there is one split and no stages in between, and a [graph](/docs/flow/graph/) when the connections matter more than the amounts.

## A basic sankey

Set `type` to `"sankey"` and give it one row per link, with a source, a target and a value. The three encoding channels name those fields. Nodes are placed in columns by their depth in the flow, except that by default every node with no outgoing links moves to the last column.

Labels in the first column sit to the left of their nodes, labels in the last column to the right, and labels in the columns between to the right. Each label is the node name with its value beside it, formatted by the `format` on the value channel.

The figure below is Lawrence Livermore National Laboratory's 2024 US energy flow: fuels feed electricity generation and the four end-use sectors, and each sector's energy ends as either energy services or rejected energy. It uses all 42 labelled links and leaves out only an unlabelled hairline.

The diagram draws once the page's script runs, so the figure reserves its height until then. Hovering a node or a ribbon highlights every link and node upstream and downstream of it and dims the rest.

## A funnel

A funnel is a sankey whose drop-off branches end early. Each stage splits into the readers who go on and the ones who leave, so the losses read as clearly as the conversions. The default `nodeAlign: "justify"` would move Bounce, Drop Off and Churned to the last column; `nodeAlign: "left"` keeps each one beside the stage it leaves. `",.0f"` on the value channel prints whole numbers with thousands separators.

## Link color

Nodes take the palette's colors in turn. `linkStyle` sets how the ribbons between them are colored: `"gradient"` (the default) runs from the source node's color to the target node's color, `"source"` and `"target"` use one end's color all the way, and `"neutral"` uses the theme's gridline color. Coloring by source makes it easy to follow one source, such as petroleum, to every place it goes.

<Demo id="flow/sankey-link-color" />

## Merging small nodes

`other` merges nodes that carry less than a share of their column's total into one node named "Other", drawn in a neutral color. Here solar and wind each carry under 7% of the sources column, so they merge. Links into and out of merged nodes move to the new node, so the total flow does not change. A column with only one node under the threshold is left alone, and `{ threshold, label }` renames the merged node. Without `other`, every node is drawn.

<Demo id="flow/sankey-other" />

## Formatting values

The value channel's `format` takes a d3-format string and applies to every label. `"$,.1f"` prints a dollar sign, thousands separators and one decimal, which suits amounts in millions.

## On a phone

When the labels outside the first and last columns would leave the ribbons less than half the width, which happens on most phones, the labels move onto the flow. Labels in the first and middle columns sit just right of their node, labels in the last column just left of it, and each wraps within the gap to the next column with its value on its own line below.

A halo in the background color keeps each label readable over any ribbon, and labels on small neighboring nodes are nudged apart. Setting `nodeLabelAlign` to `"left"` or `"right"` keeps labels where you put them at every width.

A phone also has less room for a long tail of small nodes. `overrides` changes fields at one breakpoint, `compact` under 400px or `medium` from 400 to 700px: `chrome` merges with the top-level chrome, and `other`, `nodeSort`, `nodeLabelAlign` and `nodePadding` replace their top-level values. This folds every node under 2% of its column into "Other" on phones only:

```json
{
  "overrides": {
    "compact": { "other": 0.02 },
    "medium": { "other": 0.02 }
  }
}
```

## Fields that matter

| Field | What it does |
| --- | --- |
| `type` | `"sankey"` selects this visualization. |
| `data` | One row per link. |
| `encoding.source`, `encoding.target` | The fields that name each link's two nodes. |
| `encoding.value` | The field that sets each ribbon's width; its `format` sets the label numbers. |
| `nodeAlign` | `"justify"` (the default) moves nodes with no outgoing links to the last column; `"left"` keeps each at its depth. `"right"` and `"center"` are also available. |
| `linkStyle` | `"gradient"`, `"source"`, `"target"` or `"neutral"` ribbon color. Default `"gradient"`. |
| `other` | A share of the column total below which nodes merge into "Other". Off unless set. |
| `overrides` | Fields that change at the `compact` or `medium` breakpoint. |
| `chrome` | The title and subtitle above the diagram. |

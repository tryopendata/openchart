A lollipop chart is a bar chart with the bar thinned to a stem and a dot at the end. The reader still judges each value by its distance from the baseline, with less ink. It uses less ink than bars, which helps on a long list. The stems are still lengths, so keep the axis at zero; for dots on an axis that starts elsewhere, use a dot plot with `mark: { type: "point", trendline: false }` and no stems, as on the [scales page](/docs/the-spec/scales/).

Use a [bar chart](/docs/comparison/bar/) when the filled length should dominate, and a [range chart](/docs/comparison/range/) when each category has a start and an end value.

## A basic lollipop chart

Set `mark` to `"lollipop"`, put the number on `x` and the category on `y`. Each stem runs from the zero baseline to its dot.

<Demo id="comparison/lollipop-basic" />

## Positive and negative values

Stems run left of zero for negative values, so a lollipop chart shows decline as clearly as growth. A solid `refline` at `x: 0` marks the baseline.

<Demo id="comparison/lollipop-diverging" />

## Two values per category

On the dot mark, a categorical `color` field switches the chart to dumbbell mode, which joins each category's dots from lowest to highest and drops the stems from zero. Set `scale: { zero: false }` on `x` so the axis spans the data instead of starting at zero. When your data already has a start and an end column per row, use the [range mark](/docs/comparison/range/) instead.

## Fields that matter

| Field | What it does |
| --- | --- |
| `mark` | `"lollipop"` and `"circle"` draw dots on stems. |
| `encoding.x` | The value channel. Required, `type: "quantitative"`. |
| `encoding.y` | The category channel. Required, `type: "nominal"` or `"ordinal"`. |
| `encoding.color` | A categorical field switches to dumbbell mode (dots joined per category, no stems); a quantitative field colors the dots on a sequential scale and keeps the stems. |
| `encoding.x.scale.zero` | `false` stops the axis from including zero. |
| `annotations` | A `refline` draws a reference value in data units. |

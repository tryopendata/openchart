A symbol map puts a circle on each place, sized by a value. It suits totals, such as an economy's output or a country's population, because the circle's area carries the number and the size of the region underneath does not.

Use a [choropleth](/docs/maps/choropleth/) for rates and shares that belong to a whole region, and a [bubble chart](/docs/correlation/bubble/) when position should carry two more numbers instead of a location.

## A basic symbol map

Symbols go in the `points` layer of a `"map"` spec: its own `data`, and `longitude` and `latitude` channels naming the coordinate fields. `size` maps a number to the circle's area, so the radius grows with its square root, and a size key of nested circles explains the scale. With a points layer the map needs no data of its own: `data: []` and no `color` channel draw the states as a plain basemap.

<Demo id="maps/symbol-basic" tabs={false} />

These datasets name states and countries without coordinates, so each symbol sits at the center of its state's outline, worked out from the same atlas the map draws. The [choropleth page](/docs/maps/choropleth/#passing-the-geography) shows how to pass an atlas in your own code. Larger circles draw first, so a small one is never hidden behind a large one.

## Color as a second value

`color` on the points layer maps a second field to the fill, with its own legend and a scale separate from any region colors. Here size is GDP and color is population. `legend.position: "bottom-right"` puts the color legend and the size key in the right-hand gutter, aligned to the bottom.

## A world symbol map

The same layer works on a world map. Here the basemap is the `land` object of `world-atlas`, all land as one shape with no country borders. `projection: "equalEarth"` keeps areas true to size.

## Symbols over a choropleth

A spec can carry both layers: `data` and the `color` channel color the regions, and the points layer draws on top. Each layer keeps its own legend, so a rate per state and a total per state read together.

## Fields that matter

| Field | What it does |
| --- | --- |
| `points.data` | The rows for the symbols, separate from the map's own `data`. |
| `points.longitude`, `points.latitude` | The fields holding each symbol's coordinates. |
| `points.size` | A number mapped to circle area. |
| `points.color` | A field mapped to fill, nominal or quantitative, with its own scale. |
| `points.key` | A stable id for each symbol, used for events and to match symbols across updates. |
| `points.tooltip` | The fields shown when a reader hovers a symbol. |
| `geo.features` | The basemap topology, drawn under the symbols. |
| `legend.position` | Where the legends sit, such as `"bottom-right"`. |

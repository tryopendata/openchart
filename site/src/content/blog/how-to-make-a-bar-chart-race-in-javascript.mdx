China's economy passed Japan's in 2010 and reached $18.7 trillion in 2024, 65% of the United States' $28.8 trillion, according to the World Bank. A bar chart race shows that climb a year at a time: the 10 largest economies are bars sorted by size, and the bars slide past each other as each year's numbers arrive. In OpenChart a race is a spec with `type: "race"`, three encoding fields and one row per country per year.

The race runs 31.5 seconds, 700 milliseconds for each of the 45 years. The control strip under the chart pauses, plays and scrubs to any year, and with focus on the strip the arrow keys step one year at a time.

## The data: one row per entry per period

A race reads long data, one row for each country in each year:

```ts
const rows = [
  { country: "China", year: 2009, gdp: 5190e9 },
  { country: "China", year: 2010, gdp: 6193e9 },
  { country: "Japan", year: 2009, gdp: 5289e9 },
  { country: "Japan", year: 2010, gdp: 5759e9 },
  // ...one row per country and year
];
```

The World Bank's download, like most spreadsheets, is wide: one row per country and a column per year. Reshape it before it goes in the spec:

```ts
const rows = wide.flatMap(({ country, ...byYear }) =>
  Object.entries(byYear)
    .filter(([, gdp]) => gdp !== "" && gdp != null)
    .map(([year, gdp]) => ({ country, year: Number(year), gdp: Number(gdp) })),
);
```

The filter matters because `Number("")` is 0, and a blank cell would otherwise rank as an economy of zero dollars.

Each country gets at most one row per year. Two rows with the same country and year stop the race with an error that asks you to aggregate them first, and the data needs at least two periods. A period can be a number, a date or a label such as `"2023-Q3"`. Numbers and dates sort by value; labels keep the order they first appear in unless `encoding.time.sort` lists them.

## A complete race spec

## Top N, speed and scale

`race.top` sets the number of slots, 10 by default. Each extra slot makes every bar thinner, so pick the smallest number that holds the story. Five slots show every change among the leaders. Ten add the climbs further down: China starts 12th in 1980 and India 13th, and India is 5th by 2024.

Playback defaults to 700 milliseconds per period, with the total kept between 8 and 90 seconds. Set the total in milliseconds with `race.duration`, as the spec above does with 20 seconds, or the time per period with `race.step`, but not both. The last frame holds for 1.5 seconds (`race.holdEnd`), and `race.loop: true` starts over after it.

By default each frame fits its scale to the bars on screen (`race.rescale: "frame"`), so the leader's bar stays near full width and the others read as fractions of it. `rescale: "fixed"` keeps one scale for the whole run, which shows real growth: the United States' bar in 1980 is a tenth of its 2024 length. `race.rescale: { min }` sets a floor on the frame's maximum, so a race that starts small doesn't open with bars stretched to full width.

## Gaps, late starters and ties

A country with no rows before some year enters the race that year. The World Bank's series for Russia starts in 1988, so Russia appears then. The World Bank publishes no Soviet series, so the 1980s rankings have no entry for the Soviet Union at all. Check what your data leaves out before you publish a ranking.

A missing year between two observed ones is filled by interpolating between them, the default `race.gaps: "interpolate"`. `"hold"` carries the last value forward, and `"drop"` takes the entry out of the ranking until its next value.

Ties keep the previous period's order. In this data, which is rounded to the billion, Canada and India both have $1,828 billion in 2012, tied for 10th. India was ahead in 2011, so India keeps 10th and Canada drops out. Entries with no earlier order fall back to alphabetical order by key.

## Lines and tables

The same spec draws lines or a table when you change `mark`. `mark: "line"` traces each ranked economy up to the playhead, and the x axis widens as the years go by. `mark: { type: "line", window: "all" }` shows all 45 years from the start.

The lines keep the history that bars throw away. Japan's economy peaked at $6.27 trillion in 2012 and fell to $4.03 trillion by 2024, and both points stay on screen while the race goes on.

`mark: "table"` lists rank, the change in rank since the previous period, name and value, and the rows slide when the order changes. The default columns also include an inline bar and each entry's share of the total. This one lists four columns so the names fit on a phone.

## Playback and reduced motion

`race.autoplay` defaults to `"visible"`, which starts the race when a quarter of it is in view. `true` starts it at mount, and `false` waits for the play button. Readers who have asked their system for reduced motion get the race paused on its last frame. They can still scrub, and pressing play steps through one year at a time instead of sliding. `race.controls: false` removes the control strip.

The player that `createRace` returns has `play()`, `pause()` and `seek(index)`, which takes a zero-based period index; fractions land between periods. `on("period", callback)` fires each time the playhead crosses a period.

Screen readers get a description that names the first and last leaders, a table of the top entries by period, and a live region that announces the leaders when the reader pauses, steps or scrubs. It stays quiet during playback, so a screen reader isn't reading a new ranking every 700 milliseconds.

For readers without JavaScript, or for an image in a newsletter, `renderRaceStaticSVG(spec)` from `@opendata-ai/openchart-vanilla/static` draws the final period as an SVG string without a browser. `renderStaticSVG` accepts race specs too. `createRace` adds the live race to its container without clearing it, so remove the static SVG before you mount the race.

## In React, Vue or Svelte

Each framework package exports a `Race` component that takes the same spec:

```tsx
import type { RaceSpec } from "@opendata-ai/openchart-core";
import { Race, type RaceHandle } from "@opendata-ai/openchart-react";
import { useRef } from "react";

export function GdpRace({ spec }: { spec: RaceSpec }) {
  const race = useRef<RaceHandle>(null);
  return <Race ref={race} spec={spec} style={{ height: 520 }} />;
}
```

`race.current?.instance` is the same player that `createRace` returns. Vue and Svelte import `Race` from `@opendata-ai/openchart-vue` and `@opendata-ai/openchart-svelte`.

## Exporting a GIF for social posts

`await player.export("gif")` records the whole race, from the first period through a 1.5-second hold on the last, and returns a `Blob`. It needs the optional `gifenc` package (`npm install gifenc`) and works for bar and line races; switch a table race to bars first. The GIF is drawn at the race's current size in pixels, so size the container to the image you want before you call it.

`fps` sets frames per second, 25 by default. A GIF gets at most 1,199 frames, so a race longer than about 48 seconds exports at a lower frame rate. The GIF loops when the spec sets `race.loop: true` and plays once otherwise. [Export a chart as PNG, SVG or GIF](/blog/export-a-chart-as-png-svg-or-gif/) has a short function that saves the `Blob` as a file.

Every race option, including the table columns and the scale floor, is on the [race docs page](/docs/change-over-time/race/).

# OpenChart brand

The mark is four cells, one chart mark in each: a bar, a point, an arc and an area.
Each cell takes one series color, so the logo reads as the library's vocabulary and as
a small multi-series chart. All SVGs are plain filled shapes with no masks, fonts or
IDs, so several can be inlined on one page.

Everything here is generated by `source/build.mjs`. Change the geometry or colors
there, then run `node brand/source/build.mjs` from `site/` and commit the result. The
script also copies the files the site serves into `public/`.

## Colors

The four hues follow the chart library's categorical palette order (cyan, ochre, blue,
rose), brightened for use as flat fills.

| Shape | Light     | Dark      |
| ----- | --------- | --------- |
| Bar   | `#3d6fe0` | `#6591e1` |
| Point | `#e8a23a` | `#f9be78` |
| Arc   | `#d1458f` | `#d771a4` |
| Area  | `#0a9cb5` | `#22d3ee` |
| Ink   | `#101010` | `#f2f2ee` |

On the site the mark reads these through the `--brand-bar`, `--brand-point`,
`--brand-arc` and `--brand-area` tokens in `src/styles/global.css`. Use the one-color
versions (`-black`, `-white`) wherever color isn't available.

## Files

| File                                | Use                                                                                          |
| ----------------------------------- | -------------------------------------------------------------------------------------------- |
| `svg/openchart-horizontal.svg`      | Default logo. `-dark`, `-black`, `-white` variants.                                          |
| `svg/openchart-stacked.svg`         | Square-ish spaces. `-dark` variant.                                                          |
| `svg/openchart-mark.svg`            | Mark alone at 32px and up. `-dark`, `-black`, `-white` variants.                             |
| `svg/openchart-mark-small.svg`      | Mark below 32px. Drawn on a 16px grid so every edge lands on a whole pixel. `-dark` variant. |
| `svg/openchart-mark-animated.svg`   | The mark dropping in and bouncing into place, once. `-dark` variant. See Animated mark.      |
| `svg/openchart-wordmark.svg`        | Wordmark alone. `-white` variant.                                                            |
| `favicon.svg`                       | Browser tab icon; switches to the dark hues with the system theme.                           |
| `favicon.ico`                       | 16, 32 and 48px. 16 and 32 use the small mark.                                               |
| `apple-touch-icon.png`              | 180px, mark on white.                                                                        |
| `png/icon-192.png`, `icon-512.png`  | Web app manifest. The mark sits inside the maskable safe zone.                               |
| `og-image.png`                      | Social preview, 1200x630. `png/openchart-og-2400x1260.png` is the 2x copy.                   |
| `png/openchart-social-1280x640.png` | GitHub repository social preview.                                                            |
| `png/`, `webp/`                     | Raster mark and lockups for tools that don't take SVG. WebP copies are lossless.             |

```html
<link rel="icon" href="/favicon.ico" sizes="48x48" />
<link rel="icon" href="/favicon.svg" type="image/svg+xml" />
<link rel="apple-touch-icon" href="/apple-touch-icon.png" />
<link rel="manifest" href="/site.webmanifest" />
<meta property="og:image" content="https://openchart.steamfield.io/og-image.png" />
```

Docs pages get their own social card from `src/lib/og.ts`, which draws the small mark
beside the site name. Its four hex values repeat the light column above.

## Usage

Leave clear space around the logo equal to one cell of the mark on every side. Use the
small mark below 32px. Don't recolor a single shape, reorder the cells, rotate the mark,
add effects, or set "OpenChart" in another typeface beside it.

## Animated mark

`source/bouncing-mark.mjs` solves a small bounce for each shape (gravity, a share of
speed lost at every impact, drift and spin that die out the same way) and writes it as
CSS keyframes inside the SVG, so the file plays without script, once, and ends as the
plain mark. It stays still under `prefers-reduced-motion`. The shapes fall in from above
the artboard: inline the SVG to let them show outside its box, since an `<img>` clips
them to it. Its class and keyframe names start with `ocb` and are global, so inline it
once per page. For the site header the build also writes the small cut's motion to
`src/styles/brand-mark-motion.css`, which `src/layouts/BrandMarkAnimated.astro` pairs
with the shapes. Tune the motion in the `SHAPES` table and the constants above it.

## Wordmark

Schibsted Grotesk Bold, tracking -25/1000 em, outlined to paths. It is the site's sans,
under the SIL Open Font License (`source/fonts/OFL.txt`). The static cuts in
`source/fonts/` were instanced from the variable font in
`@fontsource-variable/schibsted-grotesk` with
`fonttools varLib.instancer <file> wght=700` (and `wght=400`). As live HTML text, use
`font-weight: 700; letter-spacing: -0.025em`.

# OpenStudio

The browser authoring app moved to [tryopendata/openstudio](https://github.com/tryopendata/openstudio). Its [GitHub Pages demo](https://tryopendata.github.io/openstudio/) runs entirely in the browser, without a backend. Local data imports, authoring controls, drafts, portable projects and exports belong to that repository.

OpenStudio consumes published OpenChart packages. OpenChart retains the reusable [spec and authoring APIs](spec-reference.md#authoring-foundation-additions), [reader and lifecycle contracts](architecture.md), themes, and deterministic motion. Its packages do not include Studio UI or dependencies.

See OpenStudio's [authoring guide](https://github.com/tryopendata/openstudio/blob/main/docs/authoring.md) for capabilities, local data storage, development and hosting.

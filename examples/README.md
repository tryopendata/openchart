# Examples

Interactive stories for developing and testing OpenChart components. Powered by [Ladle](https://ladle.dev).

## Folder structure

- `src/charts/` - Chart type demos (bar, line, scatter, pie, etc.)
- `src/editorial/` - Publication-quality examples styled after real data journalism
- `src/` (root stories) - Feature demos: animation, theming, responsive behavior, transforms, conditional formatting
